# 分析框架（Analysis Framework）

用于把事实转为判断的分析镜头。框架 Agent 与三路分析 Agent 共同使用；每支镜头输出"判断 + 证据 + 置信度"。

## 主要镜头

1. **主线压缩**：从证据中提炼一句话可验证、可推翻的核心判断，含时间窗口。
2. **规模与需求底线**：市场总空间 vs 真实可支付需求；量×价拆解，确认增长不是统计幻觉。
3. **利润池与价值迁移**：价值在产业链环节分布，利润从哪流向哪，迁移的驱动和速度。
4. **竞争格局与终局**：集中度变化、关键成功要素、终局形态（寡头/长尾/分化）与反转信号。
5. **驱动—制约矩阵**：需求、技术、政策、成本、竞争五维，各自力号与方向。
6. **周期定位与供需**：行业处于导入/成长/成熟/衰退，供需缺口与价格趋势。
7. **政策传导**：政策如何影响需求、成本、供给、商业化和估值，边际变化在哪里。
8. **盈利质量与回报**：ROE/ROIC、毛利率、现金流、CAC/LTV、回本周期，识别会计与经营质量。
9. **预期差**：市场共识 vs 本报告判断的差异，反方观点及回应。
10. **证伪与终止条件**：什么信号出现即推翻判断（T 信号），及时止损避免固执。

## 使用方式

每个镜头产出三件套：判断句、支撑证据（source_id/card_id）、置信度与待验证点。数据不足的镜头如实写"公开信息有限"，不硬凑结论。
