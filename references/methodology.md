## 二、数据交叉验证原则

### 可信度分级

- **🟢 高可信**：国家统计数据、上市公司经审计年报、权威机构白皮书
- **🟡 中可信**：第三方研究报告、行业协会公开数据（需注明估算方式）
- **🔴 低可信**：单一来源、网友爆料、无来源引用的"据说"数据

### 验证流程

```
单一来源数据
    ↓ 是否有第2来源？
    ├─ 有 → 两来源对比，差异<10%则采信，差异>10%则标注差异
    └─ 无 → 标注"⚠️ 待核实 / 据估算 / 单来源"
```

## 三、用户需求验证方法

### 公开信息验证用户真实需求

1. **搜索"品牌名+投诉/差评/坑"** → 找到真实不满点
2. **搜索"品牌名+怎么样/好用吗"** → 了解用户真实评价
3. **电商平台评论区** → 真实用户使用反馈
4. **小红书/抖音种草内容** → 用户愿公开表达的需求

### 需求真伪判断框架

| 类型 | 表现 | 判断 |
|------|------|------|
| 真实刚需 | 愿意排队、付溢价、多渠道比较 | ✅ 强需求 |
| 表面需求 | 说想要但付费转化低 | ⚠️ 谨慎判断 |
| 伪需求 | 用户口头认可但无后续行为 | ❌ 避开 |

## 四、盈利模式拆解参考

### 关键指标计算

```
LTV（用户生命周期价值）= 单用户平均收入(ARPU) × 平均用户生命周期(月) × 毛利率
CAC（获客成本）= 总营销费用 ÷ 新增付费用户数
回本周期 = 固定成本 ÷ (月均收入 - 月均变动成本)
健康线：LTV > 3×CAC
```

### 各行业盈利特征参考

| 行业 | 常见盈利模式 | 典型CAC | 典型LTV/CAC |
|------|------------|--------|------------|
| 电商零售 | 差价/自营 | 50~200元 | >3 |
| SaaS/工具 | 订阅制 | 500~3000元 | >3 |
| 内容订阅 | 会员制 | 20~100元 | >5 |
| 教育培训 | 课程/会员 | 100~500元 | >3 |
| 餐饮零售 | 单次消费 | 10~50元 | 差异大 |

## 五、市场规模估算方法

### 自上而下法（Top-down）

```
目标市场规模 = 可服务市场(TAM) × 可达率
可服务市场 = 潜在用户数 × 渗透率 × 客单价 × 复购频次
```

### 自下而上法（Bottom-up）

```
目标市场规模 = 潜在用户群体 × 转化率 × 覆盖份额 × 客单价
例：大学生知识付费市场
  = 全国大学生数量(4000万) × 付费意愿比例(15%) × 年均消费(300元)
  = 18亿元
```

### 交叉验证

两种方法估算结果取交集或中位数，差异过大时以更保守的数字为基准。

## 七、行业周期判断框架

```
萌芽期：
  - 特征：玩家少、模式不清晰、用户认知低、资本观望
  - 判断依据：近期无/少融资、产品未规模化、媒体曝光少

增长期：
  - 特征：玩家增多、资本蜂拥、用户增速快、模式跑通
  - 判断依据：融资事件密集、头部玩家用户量季度增速>30%

成熟期：
  - 特征：头部格局稳定、增速放缓、细分赛道分化
  - 判断依据：头部市占率>50%、行业整体增速<20%

饱和/衰退期：
  - 特征：用户总量趋降、竞争激烈、利润压缩
  - 判断依据：多家头部玩家亏损、关停事件频发
```
