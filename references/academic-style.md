# 学术写作规范（格式/内容/语言/适配）

本文件收录项目使用的学术规范要求，作为 writer/各审核 agent 的**格式与表达依据**（第一优先级）。市场调研报告按此规范落地的适配说明见各条「适配」注。

## 一、格式规范要求

1. **报告结构**（学术论文九章范式 → 调研报告八分片适配）：
   - 摘要（150-200 字，明确目的/方法/结果/结论）+ 关键词（3-5 个，精准覆盖核心主题）
   - 引言（研究背景、问题提出、研究现状简述、研究意义与创新点）
   - 文献综述（系统梳理核心成果、争议焦点与研究空白）→ 调研报告以「研究现状与资料基础」小节呈现
   - 研究设计（理论框架/技术路线、研究假设/目标、数据/样本来源、研究方法/实验设计）→ 以「研究方法与数据说明」呈现
   - 实证分析/结果呈现（数据描述、模型检验/实验验证、核心结果可视化）
   - 讨论（结果解读、与现有研究的对比、价值阐释）
   - 结论与展望（核心发现、局限、未来方向）
   - 参考文献
2. **章节层级**（调研报告落地）：
   - 一级标题：`一、二、三、…`（中文数字）
   - 二级标题：`（一）（二）（三）…`
   - 三级标题：`1. 2. 3. …`
   - ✅ 禁止使用圆点 `•`、星号 `*`、emoji 等非中文序号开头的项目编号；列表一律用短横线 `-`
   - 分点式表达：开头**无需以加粗关键词+冒号引出**，直接用陈述句、短语或普通关键词引导（随后的文字可加粗，但冒号结构禁止）
3. **数据与图表规范**：
   - 定量数据配套表格/图表；表格标注表头、列名、数据单位、样本量/区间
   - 图表注明图号、图题、数据来源及关键统计参数
   - **表名在表格上方，表名与表格之间空一行**
   - **图名在图片下方，图片与图名之间空一行**
   - **图插入引用一律使用绝对路径**：`![图2 美国数据中心电力需求增长](f:\deskop\环境\图2 美国数据中心电力需求增长.png)`
   - 公式采用标准学术排版（变量斜体、公式编号居右）；所有变量/符号/缩写首次出现完整注释（定义、单位、计算方式）
   - 质性研究规范呈现访谈记录、案例资料等原始素材引用
4. **核心格式禁忌**：
   - ❌ 严禁「**加粗关键词**：后续内容」句式（如 `**核心结论**：…`、`**受益环节：**…`）
   - ✅ 替代写法：关键词不加粗（`核心结论：…`）、或陈述句引导（`受益环节包括A、B、C。`）
   - 摘要、关键词不入图表（纯文本头部）
5. **参考文献格式（GB/T 7714）**：
   - 以近 5 年核心期刊论文、权威专著、国家级项目成果、官方报告为主
   - 英文文献占比 ≥20%；避免重复引用同一文献
   - **正文标注「作者+年份」**：`（艾瑞咨询，2026）` / `据艾瑞咨询（2026）` / `（Chen & Wang, 2024）`
   - 参考文献列表按作者姓氏首字母排序（中文按拼音首字母），每条含完整著录信息

## 二、内容核心要求

1. **实证导向**：聚焦具体问题设计可检验目标/假设，避免纯理论空谈；方法适配研究问题（数据测算、案例研究、问卷、回归、实验等）
2. **数据真实性与可追溯性**：数据来自可验证来源（学术数据库/官方统计/科研实测/权威报告）；**每条数据明确标注来源**，如「数据来源：2020-2024 年某省田野调查实测数据；样本量 N=326」「数据来源：PubMed 数据库，检索关键词：XXX，检索时间：2025 年 3 月」；禁止虚构或无法追溯的数据
3. **配套可视化**：核心结果配图，图内标注数据来源、样本区间、关键统计量（p 值、R²、误差线、置信区间等）
4. **研究过程透明化**：研究设计/数据说明章节详述数据筛选标准（纳入/排除、异常值处理）、变量构建逻辑（口径、权重）、实施流程（分组、抽样），核心变量用表格呈现（定义/测量方式/数据类型/来源）

## 三、语言风格与原创性要求

1. **Nature 风格**：简洁严谨、逻辑紧凑；禁止模板化套话（"随着…的不断发展""综上所述""具有重要的现实意义"等）；核心观点开门见山、层层递进、句子精炼
2. **原创性**：禁止直接复制现有文献/模板文本；引用规范标注；创新点明确（新视角/新方法/新数据/新领域）
3. **数值精度**：百分比保留 1-2 位小数；测量数据与仪器精度匹配的有效数字；统计结果报告关键指标（N、均值、标准差、t 值、p 值、自由度、调整后 R²、置信区间）；避免模糊表述（"显著相关"需明确 p<0.05）

## 四、学科适配与创新要求

1. 研究问题聚焦前沿/现实需求，理论价值与现实意义明确
2. 创新点定位：理论创新/方法创新/数据创新/视角创新，引言与结论中明确阐述
3. **逻辑自洽**：引言提出的问题在实证中明确回应，讨论结合综述解读结果，结论凝练核心发现——全文逻辑闭环，无碎片化/重复/矛盾

## 与既有规范的优先级

- 本文档与 `report-structure.md` 冲突时以本文档为准（如：正文引用用「作者+年份」，不使用 [n] 编号制；章节二级标题用（一）体系；图引用用绝对路径）
- `chart-guidance.md` 的图表选型/规格不受影响（图题三层/选型矩阵照旧），仅图题展示位置与引用路径按本文档
