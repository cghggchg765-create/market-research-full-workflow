# 数据分级与引用纪律（Data Grading & Citation）

## 证据分级

- **A 级**：原始官方文件、公司年报/招股书、论文全文、官方统计数据库、实测原始数据。可直接作为展示值。
- **B 级**：具名研究机构、行业协会、券商/咨询报告，能定位原文。可作展示值，须显名归因。
- **C 级**：媒体转引、二手摘要、搜索摘要。仅作线索，不单独支撑关键数字。

关键数字需满足"取数通道 × 来源级别"双重约束：市场/财务数字必须来自 `seed_finance_search`（或用户文件/显名测算），来源为 A/B 级；新闻类比数字只作线索。

## 措辞纪律

| 证据档位 | 允许措辞 |
|---|---|
| A 级披露 | 可直接陈述 |
| B 级估算 | "据XX估算" |
| C 级媒体 | "据报道" |
| 推断 | "这可能意味着……后续需验证" |
| 测算 | "本研究测算，假设……" |

禁止把估算写成实际、把媒体转引写成原始披露、把不同口径数字直接拼接。

## 引用纪律

- 正文用作者/机构+年份：（艾瑞咨询，2026）、（McKinsey, 2023）。
- 参考文献按 GB/T 7714 著录，按作者姓氏/中文拼音排序；近五年优先，英文文献不少于 20%。
- 正文引用与文末参考文献双向勾稽。

## 数据准确性六维核验

每个进入正文/图表的数字在写入前对照台账核验：①值等于源值；②口径一致；③基期一致；④通道和档位合规；⑤前后一致；⑥测算可复算。无法六维核验的数字降为定性描述或删除。
