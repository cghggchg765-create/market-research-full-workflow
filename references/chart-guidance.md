# 图表编码规范（chart-coder 决策依据）

图表编码 Agent（`agents/visualizer.md`）的决策依据。**先读本文档，再决定画什么、怎么画、怎么写代码。**

## 1. 核心原则

1. **数据驱动**：只绘制分析/收集结果中真实存在的数值；没有数据就画不出图，标"数据不足"并说明缺口，不编造数字。
2. **图表为结论服务**：每张图必须支撑报告中的一个具体结论或观察，与正文数据完全一致（数字在小数点后一位内对齐）。
3. **≥5 张图**：quick ≥5 / standard 6-8 / deep 8-12。数量按**实际内容**增减，不以图片凑数；数据充分就多画，数据贫瘠就少画并标注。
4. **标题唯一归属正文**：**PNG 内不渲染主标题**——图名行「图N 标题」只出现在正文图片下方（空一行），避免"图上标题 + 文档标题"重复；图内只保留轴标签、单位、数据年份，**来源以小字标注在图内底部**，图内与图注不出现 ✅/🟡/⚠️ 等符号标记。
5. **PNG + mermaid 混合**：数据类图（柱状/折线/饼/雷达/矩阵）→ PNG（matplotlib 生成，中文用微软雅黑）；流程/时序/规划类图 → mermaid 代码块（不占图号、不入图表清单，Writer 直接写在对应小节，飞书渲染为画板、本地 Typora/VSCode 可预览）。

## 2. 选型矩阵：数据形态 → 图型

| 数据形态 | 适用图型 | 典型场景 | 生成方式 |
|---------|---------|---------|:-------:|
| 时间序列（市场规模/增速/用户数逐年） | line（折线，可双轴量纲不同） | 行业定义章市场规模与增速 | PNG |
| 构成占比（份额/收入构成/成本占比） | donut（环形）或 pie | 结构章市场份额、成本结构 | PNG |
| 横向对比（竞品多维度评分） | radar（雷达） | 竞争要素矩阵 | PNG |
| 类别数值对比（价格带/客单价/频次） | bar 或 hbar（水平适合长标签） | 头部玩家、痛点频次 | PNG |
| 类别 + 多系列（分组对比） | bar（分组柱状） | 利润空间对比、LTV/CAC | PNG |
| 多维构成累加（收入构成分层） | stacked_bar（堆叠柱状） | 商业模式收入构成 | PNG |
| 概率×影响（风险/机会评估） | heatmap（风险矩阵）或 scatter（象限图） | 风险评分卡、差异化机会 | PNG |
| 经济模型（LTV/CAC/回本周期） | bar 分组 + 阈值线说明 | 盈利质量分析 | PNG |
| 流程/链路（产业链/决策链路/商业模式画布） | mermaid flowchart | 产业链、决策链路 | mermaid |
| 时序规划（90天/6个月/12个月） | mermaid gantt | 分阶段落地计划 | mermaid |
| 用户分层/规模估算 | bar 或 stacked_bar | 用户分层 | PNG |
| 年份事件/里程碑 | mermaid timeline | 行业周期与事件 | mermaid |

## 4. 图表清单 chart-manifest.json（PNG 部分）

图表编码 Agent 逐图编写 `{run_dir}/scripts/charts/fig_{NN}_{slug}.py` 并用任务虚拟环境运行；全部 PNG 就绪后，把每张图登记为清单 `charts/chart-manifest.json` 的一个条目（数组按报告出现顺序排列）：

```json
[
  {
    "id": "chart-01",                 // 编号，与报告图号一致（图1...图N）
    "type": "line",                   // bar/hbar/stacked_bar/line/pie/donut/radar/scatter/heatmap（信息性）
    "title": "市场规模与增速趋势（2022-2027E）",  // 将写入正文图名行「图1 {title}」
    "display_name": "图1 市场规模与增速趋势.png", // 交付语义文件名（与 charts/ 磁盘一一对应）
    "script": "fig_01_market_size.py",           // 生成该图的脚本文件名（{run_dir}/scripts/charts/ 下）
    "card_id": "K03",                 // 必须绑定知识卡片
    "source_id": "SRC-003",           // 必须绑定证据台账
    "year": 2026,
    "unit": "亿元",
    "definition": "明确指标定义和统计口径",
    "base_period": "2022-2025",
    "source": "艾瑞咨询 2026；估值",
    "notes": ["2026-2027E 为预测值"],  // 口径说明（可选）
    "position": "2.2 市场规模与增速"   // 插入报告位置（章节标题，防漂移依据）
  }
]
```

- 文件名 **display_name 以「图N …」开头**，脚本内部可另存 `fig_{NN}_{slug}.png` 中间态，交付只认 display_name；
- mermaid 流程类图**不入清单**（不占图号，Writer 直接内嵌代码块）。

### 代码内数据形态（各图型参考结构）

写脚本时按数据实际情况组织，不必照抄模板；以下为常见结构参考：

| type | 常用数据结构 |
|------|----------|
| bar / hbar / stacked_bar | `categories`: [标签], `series`: [{"name","values"}]，values 支持数字或 "1,200" 字符串 |
| line | `x`: [年份/标签], `series`: [{"name","values"}]；双量纲系列（如金额+增速）用双 y 轴并注明单位 |
| pie / donut | `labels`, `values`, 环形可加中心文字（如 "TOP5 68%"） |
| radar | `categories`, `series`（评分统一 0-10 或同量纲） |
| scatter | `points`: [{"x","y","label"}], `xlabel`, `ylabel`；象限图画象限参考线并标注象限名 |
| heatmap | `rows`, `cols`, `matrix`: [[...]], 色带按风险语义用红黄绿或 YlOrRd，加 colorbar 标签 |

### 标注与命名规范

- 轴/系列命名 = 指标 + 单位：`'市场规模（亿元）'`、`'同比增速（%）'`；
- 场景/阵营名 ≤12 字（过长拥挤）；
- 数据点标签直接上标（不依赖 hover 也能读数）；长分类名用 `\n` 换行或缩短；
- **图内不渲染主标题**（axes.set_title 只用于空画布自测，正式图不使用）；图内底部用 `fig.text` 小字标注来源行，如「数据来源：国家统计局、XX研究院，本研究整理」；
- 源标注含年份：`{机构} {年份}`；估算值在图内或 notes 中注明"估算/预测"。

### 选型口诀补充

- 量级跨度大（跨 2-3 个数量级）→ 横向条 + 对数轴（matplotlib 支持 `set_xscale('log')`；读者不易读时用分段/注释替代并说明）
- 占比 + 多维禀赋 → 饼 + 雷达双拼（各占一张图，位置相邻）
- 结构演变（占比随时间迁移）→ 堆叠柱
- 架构分层关系 → mermaid 流程图
- 情景推演 → 多系列折线（乐观/中性/悲观）
- 二维评估 → 散点矩阵（象限线）

**运行方式**（图表编码 Agent 执行；CWD=运行目录，解释器=任务虚拟环境，二者由编排者按 `SKILL.md` 运行时契约注入）：
```text
{task_python} {run_dir}/scripts/charts/fig_01_*.py
```
脚本须自带中文字体注册与布局自检（`tight_layout`/画布尺寸按标签数调整）；运行失败读报错修改重跑，每图 ≤3 轮；全部成功后才写 `charts/chart-manifest.json`。`scripts/charts/gen_chart.py` 保留为可选的模板参考/兜底渲染器（`--spec` 兼容本清单结构），**不强制使用**。

## 5. mermaid 部分规范

mermaid 由 Writer 直接以代码块写在对应小节（不占图号、不入清单）：

```mermaid
flowchart LR
  A[上游...] --> B[中游...]
```

语法要求：
- flowchart：节点用中文，箭头语义准确，控制节点数 ≤12；
- gantt：`dateFormat YYYY-MM`，里程碑用 `milestone`；阶段 90天/6个月/12个月；
- **禁止** mermaid pie（中文字体在部分渲染器乱码，构成类一律 PNG 环形图）。

## 6. 扩展图型决策库（AI 按需实现，非固定清单）

行业报告高频图型不止基础 8 类。下表结合七章报告结构（`industry-report-standard.md`）与 2026-09 数据可视化调研归纳扩展图型。**图表编码 Agent 依据「数据能回答什么问题」自主实现**，本表只给「何时用 / 数据要求 / 章节落点 / matplotlib 实现要点」，不给死模板；可自由组合或自定义。需第三方库（如 squarify/networkx）时：先经编排者同意在任务 venv 安装并在清单 `notes` 记录；装不上则换等价图型。

| 图型 | 要回答的问题（何时用） | 数据要求 | 常用章节落点 | matplotlib 实现要点 | 依赖 |
|------|----------------------|---------|:-----------:|--------------------|:----:|
| 瀑布桥 waterfall/bridge | 一个总量如何被逐项增减拆成另一总量（收入→净利；规模同比增量按量/价/结构归因；份额净变动拆解） | 起始值 + 有序 ±变动项 + 终值 | 六（盈利质量/单位经济）、一（增速归因） | `ax.bar(x, h, bottom=累计)`；增绿减红；中间/终点 total 用深色 | 无 |
| 堆叠面积 stacked_area | 构成随年份迁移（份额演变、收入结构演变）——避免「逐年多个 donut」 | 时间 × 多系列数值（可归一 100%） | 二（格局演变）、五（结构机会） | `ax.stackplot(x, *series, labels=…)` | 无 |
| 情景扇带 fan/区间带 | 预测与情景不确定性（中性 ± 乐观/悲观区间带） | 年份 + 三情景序列（或均值 ± 区间） | 一（规模预测）、五（趋势三情景） | 中位线 `plot` + `fill_between(low, high, alpha=.25)` | 无 |
| 气泡定位 bubble | 三维比较：位置 ×2 + 大小第 3 维（份额×增速×营收×阵营；价格×能力×规模） | 每实体 x/y/size（可选 color/象限阈值） | 二（竞争格局）、六（机会-能力） | `ax.scatter(s=size*scale)`；象限参考线与象限名文本 | 无 |
| TAM-SAM-SOM | 规模测算漏斗收缩（行业总量→可服务→可获取） | 三层数值（可含拆分）+ 单位 | 一（规模测算）、01 摘要 | 同心圆（`patches.Circle`）或嵌套气泡或三级 hbar 逐级收缩 | 无 |
| 漏斗 funnel | 单向流程逐级衰减定位瓶颈（线索→咨询→成交） | 阶段名 + 各阶段人数/金额（可含转化率） | 三（用户决策/渠道）、六（获客转化） | 对称 `barh`（宽=值/最大值）逐层居中 + 阶段标签 | 无 |
| 排名棒棒糖 lollipop | 强调 Top-N 差距与断档（痛点频次、关注度、增速排名） | 类别 + 数值（排序后） | 三（用户痛点）、四（驱动强度） | `ax.hlines` + `ax.plot(marker="o")` | 无 |
| 斜率图 slope | 两时点变化快慢/反转对比（2020 vs 2026 份额/渗透/价格） | 两时点 × 类别数值 | 二（格局演变）、四（政策/技术前后） | 左右两列 `scatter` + 逐类 `plot` 连线（两侧留白标年份） | 无 |
| 哑铃区间 dumbbell | 区间宽度对比（价格带 min-max、渗透率上下限、参数区间演变） | 每类 min/max（可加均值点） | 三（价格带）、四（区间参数） | `ax.hlines` + 端点 markers + 连接线 | 无 |
| 金字塔 pyramid | 分层数量结构（用户/客户金字塔；产业上下游分布） | 上下对称双序列或单序列镜像 | 三（用户分层）、二（产业链） | 双 `barh`（一侧负值镜像）+ 居中分隔线 | 无 |
| 分布 hist/box | 一手调研样本分布与组间差异（客户规模分布、各档客单价箱线） | 原始样本或分组分位点 | 三（一手调研）、附录（方法） | `ax.hist` / `ax.boxplot(positions=…)` | 无 |
| 桑基 sankey | 流量/资金/价值跨两段及以上节点分流（渠道归因、成本流向、产业链价值分配） | 节点层 + 流（源/目标/值）；节点 ≤10、流 ≤12 | 二（产业链价值分布）、六（资金流） | `matplotlib.sankey` 逐条叠加（流少时手绘折线也可） | 无（复杂可 networkx） |
| 矩形树 treemap | 层级占比且类别多（全量玩家份额、细分规模分层） | 层级（父-子）+ 数值 | 二（份额全景） | `squarify.plot`；备选 Top-N hbar | squarify（可选） |
| 组合标注图 annotated | 带阶段标注的演化曲线（技术成熟度/渗透 S 曲线 + 阶段文字箭头）、KPI 大数 + 微型趋势 | 曲线 + 关键节点标注 | 四（技术路线）、五（趋势） | `plot` + `annotate`/`axvline` + 坐标排版 | 无 |

选型纪律：

- 每张图先写「一句话结论」，再定图型；同一结论/同一数据只画一张图（不重复表达）。
- 扩展型同样遵守：图内不渲染主标题、来源小字在图内底部、系列 ≤5、数值与卡片一致、估算标注。
- 数据不足宁缺：无法支撑的图型不入 manifest，写入 `chart_gaps` 说明，不硬画。
- 读图门槛：桑基/树图/箱线对非专业读者有门槛——投资人/分析师读者档可用；大众读者档降级为 hbar/表格。
- 一图一结论：多角度需求拆多图或 mermaid 流程图，不在一张图内堆叠过多元素。

## 7. 自检清单（图表编码 Agent 交付前逐项过）

- [ ] 总数满足档位配额（quick ≥5 / standard 6-8 / deep 8-12）
- [ ] 扩展图型（§6）使用前自查：能写出「一句话结论」且数据可支撑——否则换基础型或入 chart_gaps
- [ ] 图号连续（图1~图N），与规划表预分配、`chart-manifest.json` `id` 一致
- [ ] 每张图脚本可重复运行（确定性数据、固定随机种子），重跑产物一致
- [ ] PNG 内无主标题（标题唯一归属正文图名行）；来源小字在图内底部
- [ ] 数据与注入包/台账一致（抽查 3 个关键数字）——不一致立即修正
- [ ] 估算数据在 source 或 notes 中标注"估算"
- [ ] 数据不足的条目不入清单，单独列出"图表缺口"说明
- [ ] 不重复表达同一数据（同一数字只画一张图）
- [ ] display_name 语义化且以「图N 」开头，不带空格外的特殊字符

## 8. 禁止项

- 无数据硬画（宁缺勿滥，标"数据不足"）
- 编造/臆测数值，或把"估算"写成"实际"
- 坐标轴截断夸大差异、饼图比例失真这类误导性画法
- 同一张图塞 >5 个系列（可读性崩塌）
- 用 emoji 当数据标签、中文乱码不做修复直接交付
- 图内或图注出现 ✅/🟡/⚠️/❌ 等符号标记（数据性质一律用文字说明）
- 图内渲染大号主标题（会造成与正文图名行的重复标题）
