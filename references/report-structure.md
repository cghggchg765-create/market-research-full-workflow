# 市场调研报告标准结构

## 报告级骨架（组装后的完整结构）

参考行业深度报告范式（案例：《大模型在保险全价值链的场景落地》3.2 万字）：

```
# 主标题（主句——破折号——反差副题）
## 核心观点（执行摘要）
## 可视化图表索引（组装时自动插入）
## 一、{行业}定义、规模测算与历史坐标
## 二、{行业}结构、竞争格局与格局演变
## 三、用户需求与行为洞察
## 四、盈利模式与可行性
## 五、风险评估与机会点
## 六、落地建议与行动计划
## 风险提示
## 结语
## 参考文献
**风险提示与免责声明：**（固定三段）
```

**编号体系**（学术层级规范）：
- 一级标题：`## 一、二、…`（中文数字），标题 = 「数字 + 主题 + 对策词」
- 二级标题：`### （一）（二）…`
- 三级标题：`#### 1. 2. …`
- 列表一律短横线 `-`（禁止 •/*/emoji 开头的项目编号）
- 尾节：每章末尾固定 `### 回扣主线`（不编号）
- 追溯引用用「板块」：执行摘要中「板块二·（二）」= 第二章第二节

**头部组件**（01 分片）：
- 主标题后写**摘要**（150-200 字：目的/方法/结果/结论）+ **关键词**（3-5 个）
- 之后才是核心观点与可视化图表索引

## 分片结构与字数配额

报告拆为 **8 个分片**，8 个撰写 agent 并行写作后组装。配额按深度档位缩放（standard 基准 32000 字，quick ×0.7，deep ×1.3），**默认 ≥30000 字**。

| 分片文件 | 章节（板块） | standard 配额 | 章节要点 |
|---------|------------|:----:|------|
| 01-executive-summary.md | 核心观点（执行摘要） | 2500 | 七段式（见下） |
| 02-industry-overview.md | 行业定义、规模测算与历史坐标 | 4500 | 定义与边界/规模多源交叉与测算/增速与生命周期/历史复盘三阶段 |
| 03-structure-competition.md | 行业结构、竞争格局与格局演变 | 5000 | 产业链三层/价值分布与利润池/头部玩家阵营/格局演变与终局/估值融资 |
| 04-user-insight.md | 用户需求与行为洞察 | 4500 | 分层画像/决策链路/需求痛点/付费意愿与价格弹性 |
| 05-business-model.md | 盈利模式与可行性 | 4500 | 盈利模型三代演进/回报率与现金流/成本结构/进入壁垒 |
| 06-risk-opportunity.md | 风险评估与机会点 | 4000 | 风险评分卡/差异化机会/战略窗口期/情景推演 |
| 07-roadmap.md | 落地建议与行动计划 | 4000 | 战略定位/分阶段计划/里程碑KPI/资源预算 |
| 08-appendix.md | 附录与尾件 | 3000 | 数据来源清单/方法论/术语/图表缺口/风险提示/结语/免责声明 |

各章至少 1500 字。组装命令：`scripts/report/assemble_report.py --parts-dir parts --out report.md --target-words {目标} --spec charts/specs.json`（生成图表索引表并校验字数/图号/引用编号/重复/语法）。

## 主线设计（贯穿全报告）

**每条报告必须有一条主线**：单句断言，含 2-3 个关键论点 + 时间窗口。框架 agent（Step 2）产出，全文回扣：

- 回扣频次：执行摘要·主线论证链（1 次）+ 每章末尾 `### 回扣主线`（8 章 → 6 次，执行摘要与附录除外）+ 结语（1 次）
- 回扣句式：「本章揭示了/印证了核心判断中『…』的论断，也为后续…提供了…基准」+ 承上启下
- 主线示例（案例）：「利润池从客服降本向风控减损迁移，合规壁垒成为头部护城河，2026—2028 年是 ROI 验证窗口期」

## 执行摘要七段式（01 分片）

头部先写摘要（150-200 字）与关键词（3-5 个），再进入：

1. **三引语块**（`>` 引用格式，关键词不加粗）：
   - `> 核心判断：`（2-3 句主论点 + 窗口期判断）
   - `> 关键风险：`（3 条）
   - `> 验证信号：`（3 条可观测指标）
2. **市场共识段**：先立靶——「市场共识认为…，这一共识已被…数据所印证（艾瑞咨询，2026）」
3. **非共识判断段**：破靶——「本报告的非共识判断在于三点：第一…第二…第三…」（每点 = 论点+数据+引用）
4. **核心数据锚点**：5 条 bullet（数字 + 单位 + （来源，年份））
5. **主线论证链**：`→` 串联各板块
6. **一句话结论**（**整句加粗**、三主体分句）：「**对险企而言…；对厂商而言…；对投资者而言…**」（整句加粗允许；禁止"**关键词**：内容"句式）

> 注：全文禁止「**加粗关键词**：后续内容」句式；强调用整句加粗。

## 章内小节结构模板

每章统一骨架：

```
## 一、{章标题}
（章首引言段：无标题，1 段。模板：「XX 的落地节奏，是 A、B、C 五股力量共同作用的结果。理解…，才能判断…」——交代本章任务与结论）

### （一）{小节标题}
（节首主题句 → 信息主体（表格或陈述句分点）→ 分析段）
#### 1. {三级要点（如需）}
### （二）…
（每章 3-6 节；带表格的节 500-900 字，纯论述节 300-500 字）
### 回扣主线
（不编号；句式：「本章揭示了…，印证了核心判断中『…』的论断，也为后续…提供了…基准。」+ 承上启下句）
```

- 表格是论证主力：每章 60% 以上小节含至少一张表；**表名在表格上方（表名与表格之间空一行）**，表后固定一行「资料来源：…，本研究整理。」
- 分点三件套（陈述句/普通关键词引导，不加粗冒号）：排序分点（`1. 战略优先级重排：…`）、强弱分点（`受益环节包括…。承压环节包括…。验证信号为…。`）、并列枚举（`①…②…③…`）
- 演化叙事模板：「第一阶段/第二阶段/第三阶段」「第一代/第二代/第三代」为最常用小节骨架
- 节首结论先行（节首 = 主题句+转折）；判断句用**整句加粗**（每章 2-4 处）
- **禁止句式**：「**加粗关键词**：后续内容」（见 academic-style.md）

## 尾件（08 附录分片内，或组装后追加）

- **风险提示**：7 条，每条格式「**序号. 风险名：**推导逻辑。**对应信号：**可观测指标（挂钩信号清单）」
- **结语**：回扣主线、点题收尾（案例句式：「真正的赢家不是…，而是…、…、…的公司。」）
- **参考文献**：`[编号] 媒体. 标题. 日期. URL`，按引用首次出现顺序编号、中文在前英文在后
- **责任声明**：固定三段「AI 自动/辅助生成、仅用于信息整理与投研辅助…；可能存在时效性不足、信息缺漏、事实误差…；用户应独立判断、自行承担…」

## 引用体系（GB/T 7714 · 作者-年份）

- 正文数据点标注「作者+年份」：`（艾瑞咨询，2026）`、`据艾瑞咨询（2026）`、`（Chen & Wang, 2024）`；机构/报告无个人作者时以机构名为作者
- 英文文献占比 ≥20%，以近 5 年（2020-2025）核心期刊、权威专著、官方报告为主，避免重复引用
- 数据真实性：所有数据标注可追溯来源（学术数据库/官方统计/实测/权威报告），禁止虚构
- 各 writer 返回「本章参考文献条目」（GB/T 7714 完整著录：作者. 题名. 刊名/出版者, 年份. 页码/URL），编排者按作者姓氏首字母（中文拼音）排序合并为参考文献
- 组装器校验：正文不得残留 `[数字]` 编号制引用（发现 → 报错提示改用作者-年份）
- 关键数字必须带（来源，年份）；本研究自测估算值注明「本研究测算」

## 表达红线

- **禁止方括号标签词**：【事实】【推断】【结论】【备注】【数据】等；数据性质融入句子自然表达（"据公司年报披露""据媒体报道"）
- **禁止符号标记**：✅/🟡/⚠️/❌ 等（内部判定只存在于审核流程，不进入报告）
- **Markdown 禁则**：列表禁星号 `*`（用 `-`）；禁止非标题语法的编号文本段（标题必须 `#` 语法）；禁止原始 HTML 标签、裸 URL、base64 图片
- 三者均为 writer 写作红线，fact-checker/quality-reviewer/polisher 三道关卡复检

## 可视化文件命名

- 图表文件交付名采用「图N + 中文标题」语义命名：`图1 不同实验组别性能对比图.png`、`表2 核心变量描述性统计表.csv`
- 内部生成文件名（chart-01-xxx.png）仅作脚本中间态；**交付时在 charts/ 目录生成同名语义副本**（`图N {标题}.png`），报告绝对路径引用指向语义副本，便于读者取用与复用
