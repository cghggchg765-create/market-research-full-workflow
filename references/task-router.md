# 任务路由

在检索前判断是否应启动完整行业报告，并将结果写入 `inputs/routing.json`。

## 触发

适用于行业全景、子赛道、技术路线、产业周期、政策主题、市场进入或商业化可行性研究。用户只问单公司、单日行情、单一财报、单一事件或一句话科普时，不启动本流程。

## 路由字段

- `report_type`：行业全景 / 子赛道 / 技术路线 / 周期位置 / 政策主题
- `industry_structure`：产业链型 / 网络型 / 资产负债型 / 单店模型型
- `decision_question`：投资 / 进入 / 战略落地 / 观望 / 退出
- `focus`：规模、竞争、政策、用户、盈利、出海等
- `exclusions`：本次不回答的窄问题

## 路由原则

- 用户有侧重点时仍保持完整行业报告，侧重点只改变章节权重。
- 行业结构决定指标和分析 playbook，不改变标准行业报告骨架。
- 发现资料不足时保留研究任务，标记证据缺口，不改为凭记忆回答。
