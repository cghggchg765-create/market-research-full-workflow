# 判断主线底稿（Judgment Spine）

框架 Agent 在写作前必先生成 `analysis/judgment-spine.md`，作为全文的尺子。证据推翻判断时先改底稿，再动正文；写每章前对照底稿回扣主线。

## 底稿结构（七格）

1. **决策问题**：读者要做什么决定（投资/进入/观望/退出），本报告为谁回答。
2. **一句话主线**：可验证、可推翻的核心判断，含时间窗口。句式：从 A 到 B 迁移 + 壁垒/条件 + 窗口期。
3. **市场共识**：已被市场接受和定价的看法（先立靶）。
4. **非共识判断**：本报告比共识多看到什么，预期差在哪（破靶）。
5. **核心数据锚点**：3-5 个数字，每个挂 source_id/card_id，用于全文数字一致性。
6. **因果链 / 利润池迁移**：关键因果链路与价值迁移方向。
7. **T 信号（验证/证伪）**：至少 5 个可观测指标，触发阈值与方向；量表可挂钩证据。

## 三情景速览

乐观 / 中性 / 悲观三档，每档给出规模或利润结果、假设、触发条件和概率（如适用），不只写假设。

## 板块子命题

六个主体板块各认领一个子命题（对主线的印证/限定/修正），并列出该板块的支撑证据 Kxx。写作时通过论证体现子命题，不写标签。
